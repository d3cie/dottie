# Contributor Covenant Code of Conduct

We pledge to make participation in Dottie a harassment-free experience for everyone. Be respectful, assume good intent, accept constructive feedback, and focus discussion on improving the project.

Unacceptable behavior includes harassment, discrimination, threats, publishing private information, and sustained disruption. Project maintainers may remove or reject contributions and participation that violate these expectations.

Report conduct issues privately to the project owner through GitHub. Reports will be reviewed promptly and handled as confidentially as practical.
